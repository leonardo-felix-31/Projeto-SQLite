# 📌 Projeto-RH-SQLite  

## 📝 Descrição do Projeto  
Este projeto consiste em um sistema de **Recursos Humanos (RH)** desenvolvido utilizando **SQLite** como banco de dados. O objetivo é gerenciar informações relacionadas a funcionários, departamentos, cargos, folha de pagamento e outros aspectos relevantes para a administração de pessoal em uma organização.  

---

## 🚀 Funcionalidades Principais  
- 👥 **Cadastro e gerenciamento de funcionários**  
- 🏢 **Controle de departamentos e cargos**  
- 💰 **Gestão de folha de pagamento**  
- 📊 **Relatórios e consultas personalizadas**  
- 📅 **Histórico de carreira dos colaboradores**  

---

## 🛠️ Tecnologias Utilizadas  
- 🗃️ **SQLite** (banco de dados relacional)  
- 🔍 **Linguagem SQL** para consultas e manipulação de dados  

---

## 📥 Como Utilizar  
1. ⬇️ Clone este repositório  
2. 🛠️ Execute o script SQL para criar o banco de dados  
3. 🔎 Utilize as consultas pré-definidas ou crie suas próprias consultas  

---

## 🏗️ Estrutura do Banco de Dados  
O banco de dados contém tabelas como:  
- **`funcionarios`** (informações pessoais e profissionais) 👨‍💼  
- **`departamentos`** (áreas da empresa) 🏛️  
- **`cargos`** (funções ocupadas) 💼  
- **`salarios`** (remuneração) 💵  
- **`beneficios`** (vantagens oferecidas) 🎁
